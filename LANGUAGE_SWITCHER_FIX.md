# Visible Language Switcher Fix

- Persian remains the default on a fresh installation.
- A visible language switcher is available on the Login screen.
- A visible language switcher is permanently available in the Main sidebar brand area.
- Persian mode uses RTL and docks the sidebar to the right.
- English mode uses LTR and docks the sidebar to the left.
- Switching language refreshes the active shell immediately and persists the preference.
